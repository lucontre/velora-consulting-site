# Velora Apps - Sitio de Consultoria

Landing bilingue (ES/EN) de la practica de consultoria: release management,
gestion de proyectos IT y automatizacion sobre Jira/JSM y Azure DevOps.

Sitio estatico de un solo archivo (index.html). Sin build, sin dependencias.

## Deploy en Vercel
1. Importar este repo en Vercel (Add New > Project > Import).
2. Framework preset: Other. Build command: vacio. Output directory: vacio.
3. Deploy.

El enlace del ERP en el sitio apunta a /erp (pendiente de enrutar al ERP real).
